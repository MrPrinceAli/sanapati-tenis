# Kebijakan Keamanan

## Versi yang didukung

Hanya commit terbaru di branch `main` yang menerima perbaikan keamanan.

## Melaporkan kerentanan

Mohon **jangan** membuka issue publik untuk masalah keamanan.

Laporkan secara privat lewat GitHub: buka tab **Security** di repositori ini lalu klik **Report a vulnerability**. Laporan dibalas dalam 7 hari, dan rencana perbaikan dibagikan kepada pelapor sebelum diumumkan ke publik.

Sertakan langkah reproduksi dan, bila ada, bukti konsep. Aplikasi ini menyimpan data akun pengguna (email, hash password, foto profil), jadi laporan tentang kebocoran data, bypass autentikasi, atau server action yang tidak terlindungi sangat dihargai.
